# Notice

LPA v1.0 is an original implementation assembled from the LPA research gates.
No FairMean, Co-teaching, DivideMix, cleanlab, VIVERE, MACSL, or Ghost Manifold
source code is vendored into the core package.

External baseline material is limited to reproducibility scripts and documented
references. The optional FairMean experiment scripts clone the authors' public
repository at run time.
